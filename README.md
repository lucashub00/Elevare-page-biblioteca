# 🚀 Elevare Soluções - Plataforma de Infoprodutos

Uma plataforma digital completa e premium para a distribuição, venda e consumo de infoprodutos (e-books, cursos em vídeo e consultorias). O sistema conta com uma Landing Page de alta conversão, sistema de autenticação e uma Área de Membros robusta com painel administrativo oculto.

## 💻 Sobre o Projeto

A **Elevare Soluções** foi desenvolvida para ser uma "Biblioteca Digital Definitiva". O design adota uma estética *Dark Premium* com detalhes em neon ciano e dourado, focado em proporcionar uma experiência de usuário (UX) sofisticada. 

O sistema é alimentado por um Backend as a Service (Firebase), permitindo o gerenciamento dinâmico de catálogos, controle de acesso de usuários e customização global sem necessidade de alterar o código-fonte em produção.

## ✨ Funcionalidades

- **Landing Page (Página de Vendas):** Apresentação do ecossistema, player de vídeo integrado (YouTube) e vitrine de pilares.
- **Autenticação de Usuários:** Login e Cadastro seguros utilizando E-mail/Senha ou Conta Google.
- **Área de Membros (Plataforma):**
  - Catálogo dinâmico de E-books com leitura de PDF via Google Drive.
  - Catálogo de Cursos com aulas demonstrativas integradas (YouTube) e links de acesso restrito.
  - Sistema de avaliação interativo (estrelas) para os produtos.
  - Central de Atendimento Integrada (Redirecionamento para WhatsApp e E-mail).
- **Painel Administrativo (Central de Comandos):**
  - Adição e remoção dinâmica de E-books e Cursos.
  - Liberação e bloqueio de acesso a produtos específicos por ID de usuário.
  - Configuração global de contatos (WhatsApp, E-mail) e mídias (Logo, Vídeo de Vendas) diretamente pelo navegador.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla/ES6 Modules)
- **Backend/Database:** Firebase Firestore (NoSQL)
- **Autenticação:** Firebase Authentication
- **Hospedagem:** Vercel / Firebase Hosting
- **Estilização:** CSS Customizado (Sem frameworks, focado em performance e customização extrema)
